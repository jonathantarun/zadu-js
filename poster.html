Problem

Dimensionality reduction (DR) techniques like UMAP and t-SNE project high-dimensional data into 2D for visualization — but every projection inevitably distorts the original geometry. How can users discover, quantify, and reduce these distortions interactively in the browser?

Distortion Types

False Neighbors

Points appear close in the 2D embedding but were far apart in the original high-dimensional space.

Missing Neighbors

Points that were genuinely nearby in the original space have been pulled apart in the embedding.

Figure 1
Conceptual diagram: original space neighborhoods (dotted circle) vs. embedding neighborhoods (solid circle), showing false and missing neighbor cases.

These two failure modes are independent — an embedding can have many false neighbors but few missing neighbors, or vice versa. Both must be measured separately.

State of the Art

  • CheckViz — server-side Python + matplotlib; not browser-native
  • Warping Index (Jaume Ros) — global distortion, no per-point breakdown
  • Hypertrix (Raval & Viegas) — focuses on projection artifacts, not neighborhood metrics
Gap: No existing tool provides real-time, per-point neighborhood distortion metrics that run entirely in the browser with zero server dependencies.

ZADU.js

A JavaScript port of the Python ZADU library. Runs client-side in any modern browser — no server, no Python, no install required.

Core Metrics (Primary)

Metric Measures Distortion
Trustworthiness T Are embedding neighbors real neighbors? False neighbors
Continuity C Do real neighbors stay close in embedding? Missing neighbors

All scores range from 0 to 1 (1 = perfect preservation).

Trustworthiness formula:
T(k) = 1 − (2 / nk(2n−3k−1)) · Σᵢ Σⱼ∈Ũₖ(i) (r(i,j) − k)
r(i,j) = rank of point j among i's neighbors in the original space; Ũₖ(i) = set of k false neighbors of i in the embedding

Continuity uses the symmetric penalty: false neighbors are swapped for missing ones. Both metrics share the same normalization factor, enabling direct comparison.

Extended Metric Suite

Metric Level Detects
Steadiness S Cluster False clusters (phantom groups)
Cohesiveness Co Cluster Dispersed clusters (torn-apart groups)
Dist. Consistency DC Global Overall distance distortion

Steadiness & Cohesiveness use HDBSCAN clustering + random walk sampling to measure cluster-level structure preservation — capturing distortions T & C miss.

Quick Start

// ES module import
import { trustworthiness, continuity }
  from 'zadu-js';

// highDim: n × d array, lowDim: n × 2 array
const t = await trustworthiness(highDim, lowDim, 10);
const c = await continuity(highDim, lowDim, 10);

// t.perPoint — array of per-point scores
// t.mean    — global score ∈ [0, 1]

Also works via CDN <script> tag — no build step required.

Conclusion

  • ZADU.js brings principled, per-point distortion metrics to the browser.
  • Trustworthiness & Continuity surface false and missing neighbors at the point level.
  • Extended metrics (S, Co) expose cluster-level distortions T & C miss.
  • Interactive demos enable metric-driven, iterative parameter tuning — no server needed.
